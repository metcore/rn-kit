

## Props

| Props      | Tipe                   | Wajib | Default | Deskripsi                                                                                      |
| ---------- | ---------------------- | ----- | ------- | ---------------------------------------------------------------------------------------------- |
| `children` | `ReactNode`            | ✅     | -       | Konten footer yang dititipkan ke slot footer milik `Provider`.                                 |
| `style`    | `StyleProp<ViewStyle>` | ❌     | -       | Gaya tambahan untuk container footer.                                                          |
| `testID`   | `string`               | ❌     | -       | ID untuk automation testing (Maestro/Detox/Appium). Diterapkan ke `SafeAreaView` footer, tanpa suffix. |
